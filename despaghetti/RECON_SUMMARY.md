## Cross-Cutting Themes

1. **God components cluster in `dashboard/`** — `progress-client.tsx` (487), `settings-client.tsx` (299), `DashboardClient.tsx` (221), `achievements-client.tsx` (140) — all in the dashboard feature folder. Dashboard is the primary de-spaghetti target.

2. **Auth forms are copy-paste siblings** — `LoginForm`, `SignupForm`, `ForgotPasswordForm`, `ResetPasswordClient` share ~70% structure (state, change handlers, submit, error alert). High-value consolidation target.

3. **Type drift is silent** — 4 exact-duplicate types (`AchievementItem`, `Notification`, `SearchEntry`, `Summary`) plus 6 feature-folder types living outside `src/types/`. Each can desync without TypeScript complaint.

4. **Dead barrel + dead UI components** — `ui/index.ts` barrel is unused (consumers bypass to direct imports); `Alert`, `Badge`, `LearningPathCard` components have no production importer. Pure dead weight.

5. **`lib/dashboard/*` returns inline anonymous types** — the lib→page→client contract is effectively undocumented; named types in `dashboard/types.ts` exist but lib functions ignore them.

6. **i18n drift in 4 components** — `Callout`, `KeyTakeaway`, `useProgress` hardcode English strings. Spanish users see untranslated labels.

7. **Dashboard test mocks duplicated** — every `lib/dashboard/__tests__/*.test.ts` re-implements chainable `SupabaseClient` mock; boilerplate is ~70% of setup.
