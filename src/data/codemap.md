# src/data/

## Responsibility

Bundled content data arrays — generated by build scripts from MDX source, consumed by loaders.

## Key Files

- `lessonBundles.en.ts` / `lessonBundles.es.ts` (and the same pattern for paths, quizzes, articles, glossary): **runtime locale modules**. Loaders and clients import these (or dynamic-import one locale). Combined `lessonBundles.ts` / `pathBundles.ts` / `quizBundles.ts` / `articleBundles.ts` / `glossaryBundles.ts` are generator output only — **do not import from `'use client'`**.
- `glossary.ts`: English term list helper (`glossaryBundles.en`)
- `lessons.ts`, `articles.ts`, `paths.ts`: Locale-agnostic ID/SSG helpers (locale files, not combined barrels)
- `learningPaths.ts`: English path list helper (`pathBundles.en`)
- `searchIndex.en.ts`, `searchIndex.es.ts`: Client-side search index (lazy-loaded per locale)
- `lessonMeta.ts`: Compact lesson id + level emit for client side-effects

## Data Flow

1. MDX files in `content/` are parsed by scripts (`scripts/bundle-*.ts`)
2. Build outputs are TypeScript arrays exported from these files
3. Loaders in `src/lib/` import these bundles for server/client consumption

## Integration

- Consumed by: `src/lib/lessons/loadLessons.ts`, `src/lib/paths/loadPaths.ts`, etc.
- Generated by: `scripts/bundle-lessons.ts`, `scripts/bundle-paths.ts`, etc.
