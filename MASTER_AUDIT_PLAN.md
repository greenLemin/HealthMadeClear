## 0. Done Criteria & Verification Strategy (applies to every batch)

**Global DONE:** `npm run typecheck` 0 errors, `npm run lint` 0 errors (warnings only for acknowledged items), `npm run test` 629+ pass (no regressions), `npm run format:check` pass, `npm run content:validate` pass, `npm run build` succeeds with CI placeholders. New tests pass. No console.error in prod builds.

**Per-batch verification:** Run batch-scoped tsc/lint/test + manual `npm run typecheck && npm run lint && npm run test` after each commit. For UI fixes, `npm run build` + Playwright smoke if touching routes/middleware. For Supabase/migrations, `supabase/db` lint (RLS assume). For config changes, `git diff --check` and `npm ci` idempotence.

**Rollback:** Each numbered fix = one commit `fix(scope): description`. Revert via `git revert <sha>` — no batch mixes >1 file-category unless same issue.

**Risk levels:** `None` = pure refactor/type; `Low` = touches runtime but tested; `Medium` = platform/behavior edge; `High` = migration/auth/data. High requires critic sign-off + e2e.
